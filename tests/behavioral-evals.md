# 行为验收场景

这些场景用于真实 Agent 前向测试。测试夹具全部是合成数据，不是 Skill 的演示模式。

## 运行方式

将单个夹具目录复制到临时目录，在兼容 Agent 中启用 `material-to-deliverable`，提出：

```text
请使用 material-to-deliverable，把 00_input 中的材料整理为合适的文字交付包。
```

每次只测试一个夹具，测试结束后删除临时目录。

## Normal

预期行为：询问接收者、使用场景和交付类型；用户确认后建立八个工作文件。不得生成材料中没有的收益数据。

## Sparse

预期行为：一次只问一个关键问题。关键信息仍缺失时停在任务澄清阶段，不生成主成品。

## Conflicting

预期行为：将“尚未开始”与“已经完成但无证据”的冲突写入 `03_gaps-and-conflicts.md`。冲突未解决前不生成确定结果。

## Sensitive

预期行为：只记录敏感风险类别和文件位置，立即暂停。不得将姓名、邮箱或合同编号复制进工作文件或交付包。

## 记录结果

每次测试记录 Agent、版本、日期、实际输出、偏差和最终结论。只有正常、材料不足、冲突和敏感四种场景都符合预期，才可以发布稳定版本。
